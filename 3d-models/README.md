# 3D Modeller

Camera Slider'ın basılması gereken parçalarının STL dosyaları.

```
3d-models/
├── slider/           Projeye özel parçalar (kendi tasarımım)
└── telefon-tutucu/   HeyVye'nin Modular Mounting System parçaları (bkz. aşağıdaki not)
```

## Baskı önerileri

| Ayar | Değer |
|---|---|
| Malzeme | PLA / PETG |
| Katman yüksekliği | 0.2 mm |
| Duvar sayısı | 3–4 |
| Doluluk | %30–40 (motor ve kayış tutan parçalarda %50) |
| Destek | Yalnızca gerektiren parçalarda |

## Telefon tutucu — atıf

`telefon-tutucu/` klasöründeki modeller **bana ait değildir**. Bu parçalar
[HeyVye](https://www.thingiverse.com/thing:2194278) tarafından tasarlanan
**Modular Mounting System** projesine aittir ve Creative Commons — Attribution
(CC BY) lisansı ile yayınlanmıştır.

Bu dosyalar projede yalnızca **destekleyici bir eleman** olarak kullanılmıştır;
kullanıcının parçaları tek tek aramasına gerek kalmasın diye orijinal
kaynaktan indirilip buraya kopyalanmıştır. Tasarımın tüm hakları ve emeği
orijinal tasarımcıya aittir.

**Bu parçaların montajı için orijinal tasarımcının sayfasındaki talimatları
izleyin:** https://www.thingiverse.com/thing:2194278

Modüller M5 cıvata/somun kullanır ve GoPro uyumlu bağlantıya sahiptir.
